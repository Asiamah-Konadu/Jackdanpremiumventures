# Jackdan Premium Ventures Web Application

> **"YOUR TRUSTED AUTO IMPORT AND EXPORT PARTNER"**

A high-performance, responsive web application for **Jackdan Premium Ventures**, an automotive import/export and logistics group based in Ghana. The platform provides global vehicle sourcing, OEM genuine auto parts procurement, real-time ICUMS import duty estimation, and live satellite container tracking.

---

## 🌟 Key Features

1. **Luxury & Commercial Vehicle Showroom**:
   - Filterable inventory (Luxury, SUVs, Sedans, Commercial Trucks) with high-res media.
   - Comprehensive vehicle specs: VIN preview, engine horsepower, transmission, mileage, and import status.
   - Multi-currency price converter (**USD**, **GHS**, **EUR**, **GBP**) with real-time conversion.
   - Dedicated vehicle inspection modal with 1-click WhatsApp booking inquiry.

2. **Genuine OEM Spare Parts Catalog**:
   - Categorized by Braking, Engine & Transmission, Suspension, Electrical, and Body.
   - **Wholesale & Retail pricing toggle** for commercial garages and private owners.
   - Direct stock availability indicator and OEM part number references.

3. **Ghana Auto Import & Customs Duty Calculator (ICUMS / GRA)**:
   - Calculate shipping freight from USA (East/West Coast), Canada, UK, Germany, UAE, Japan, and China.
   - Port of Tema & Takoradi discharge rates with GPHA terminal fees.
   - ICUMS customs duty assessment, VAT, NHIL, GETFund, and vehicle overage penalty brackets.
   - Instant quote export to WhatsApp for official clearance booking.

4. **Live Satellite Shipment & Container Tracker**:
   - Milestone progression across 5 key checkpoints (Booked → Origin Port → Ocean Transit → Tema Customs Clearance → Doorstep Handover).
   - Real-time ETA progress bars, vessel carrier info, container numbers, and chronological waybill updates.
   - Demo tracking references included (`JKD-7829-GH`, `JKD-4412-US`, `JKD-9103-DXB`).

5. **Integrated Sister Ventures Ecosystem**:
   - **Twumaasco Logistics & Trading**: Sea Freight, Air Cargo, Bonded Warehousing, Freight Forwarding, and Road Haulage.
   - **Jackdan Travel & Tour**: Worldwide Visa Advisory, Flight Bookings, Hotel Reservations, and Guided Vacation Safaris.
   - Interactive modal previews for official company flyers.

6. **Direct Concierge & Dispatch Desk**:
   - Interactive inquiry form routed directly to Jackdan dispatch officers on WhatsApp.
   - Direct click-to-call for hotlines (`+233 594 072 371` / `+233 597 840 126`).
   - Floating instant WhatsApp chat badge accessible on all screen sizes.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm / yarn

### Installation

```bash
# Clone repository
git clone https://github.com/Asiamah-Konadu/Jackdanpremiumventures.git
cd Jackdanpremiumventures

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
